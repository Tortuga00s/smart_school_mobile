# Smart School Admin — Windows

Melanjutkan prototype admin asli. Runner Windows ditambahkan karena ZIP admin belum menyertakannya. Tampilan dan fitur administratif asli dipertahankan; repository data dipindahkan ke shared package dan memakai satu demo API dengan mobile.
